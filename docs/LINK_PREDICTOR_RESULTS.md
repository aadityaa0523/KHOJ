# Link loss predictor: measured results

Generated by `./gradlew :core:trainLinkModel` on 2026-10-10. Rerun instead of editing.

**Data:** simulated phone-to-phone BLE advertising links (`RadioModel.kt`), 400 routes of 120 s, one sample per second.
The radio model's parameters are assumptions, so these numbers compare feature sets with each other;
they do not predict accuracy on real phones. The app logs the same features on real phones for retraining.

**Split:** 280 training routes, 120 held-out test routes (33880 / 14520 samples).
