# LinkFill AI: measured results

Generated by `./gradlew :core:runExperiment` on 2026-10-10. Do not edit by hand; rerun instead.

**What this is:** a simulation. Both phones run the app's real `ReliableChannel` code, but the radio link
between them is a Gilbert-Elliott bursty-loss model with assumed parameters, not a measured Bluetooth link.
Use it to compare strategies with each other, not to predict absolute performance on real phones.

Setup: one location fix per second, 20 runs of 300 s per row, location expiry 5 s.
Held-out seeds (the model was trained on different random links). Model: trained 2026-10-10, 25318 samples, seed 20261010.

Columns: **delivery** = fixes that reached the receiver within 5 s; **latency** = generation to first arrival;
**recovered** = fixes whose first transmission was lost but still arrived in time; **staleness** = age of the newest
position the receiver held, sampled every 100 ms; **bytes/fix** = all traffic both ways per generated fix.
